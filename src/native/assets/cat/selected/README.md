# Selected cat animations

Each animation has its own folder with the original SVG frames and an animation.json file specifying frame order, duration in milliseconds, and suggested looping behavior. All frames are transparent 32×32 SVGs. Swap frames in the listed order while preserving the full canvas. Appear begins with an intentionally empty frame. For one-shot animations, hold the final frame or transition to another animation.

Included: idle, blink, look, surprised, jump, run, appear, sad, grumpy, love, think, excited.
