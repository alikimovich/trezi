# Review of LKM-140, LKM-144, LKM-151, LKM-152, LKM-153 (LKM-154, 2026-10-04)

This review covers the 29 commits in `ee301e2..515779b`: every commit merged into the candidate
branch after the LKM-149 merge `ee301e2`. The candidate merges are LKM-144 (`0051c6f`),
LKM-140 (`753ceb4`), LKM-151 (`d7cfaf2`), LKM-152 (`6648298`) and LKM-153 (`515779b`).
No history was rewritten. The cleanups below are ordinary working-tree changes on top of
`515779b`.

Method:

- `git log --format='%h %p %s' ee301e2..HEAD` and `git show --stat` for every commit.
- `git show --remerge-diff` on every merge, which shows any hand edit made while resolving it.
- A tree comparison of each candidate merge with its second parent.
- `git blame` on the files that the LKM-140 iterations rewrote, to find which commits still own lines.
- `tsc --noUnusedLocals` and `biome check` on the changed files, compared with a `git archive ee301e2` baseline.
- A reference count for every symbol newly exported in the range.

## Findings by severity

### High

- **H1. The live-write guard covers one provider and four tools.**
  - `liveCheckoutEdit` (`src/main/live-write-guard.ts`) runs only as the Claude adapter's `PreToolUse` hook (`src/main/backends/claude.ts`).
  - It inspects only `Edit`, `Write`, `MultiEdit` and `NotebookEdit`. So a `Bash` write by absolute path can still reach the live checkout: `sed -i`, `>` redirection, `cp`, `mv` or a formatter run. This is the exact LKM-151 failure.
  - Other adapters (Codex, Responses) have no equivalent.
  - The LKM-151 prompt fix (project-relative selection sources) is the main defense. It is incomplete; see H2. Follow-up F2.
- **H2. Other agent prompts still carry absolute sources.**
  - LKM-151 made `describeSelectionForPrompt` project-relative (`src/shared/selection-context.ts`, `projectRelativeSource`).
  - These prompts still interpolate the raw stamp source:
    - `src/shared/controls-prompt.ts` (`element.source` and `element.componentSource`);
    - `agentPromptFor` and `textAgentPrompt` (`src/main/props.ts`);
    - `styleAgentPrompt` (`src/main/styles.ts`);
    - the Svelte variants (`src/main/props-svelte.ts`, `src/main/styles-svelte.ts`).
  - When stamps are absolute, these prompts point a worktree chat at the live tree. Follow-up F1.

### Medium

- **M1. `src/main/chat-isolation.ts` is 953 lines** (876 before the range; the guideline is about 500).
  - LKM-151 added `interrupted`/`reverted`.
  - The unpark reset now appears at 8 sites, with lines 274, 347, 368, 529, 571, 629, 644 and 665 each setting `st.parked = false`. A 9th copy is `keepStoppedTurn` in `src/main/stopped-turn.ts`.
  - Most sites reset `parked`, `interrupted`, `reverted`, `parkedFiles` and `resolvingFiles`, then call `dropParkRecord`. Some sites differ slightly, and that is how a missed flag happens.
  - Follow-up F5.
- **M2. `keepStoppedTurn` duplicates the merged branch of `afterTurn`.**
  - Both run the `recordEdit` loop with an undo group, `commitLiveTurn`, `retireWorktreeBranch` and the `merged` emit.
  - The copy in `src/main/stopped-turn.ts` reaches into `ChatState` through `stoppedTurnSeam`, which exports the mutable internal state as `IsolatedChat`.
  - A later change to the landing path, such as PR revertability or reconcile handling, has to be made twice. Folded into F5.
- **M3. LKM-153's `done` state never re-offers setup.**
  - `NativeContextController.offer` (`src/native/context-controller.ts`) returns false once `sourceSetup.state === 'done'`.
  - A project whose wiring was later removed, or whose dev server stopped stamping, keeps an unstamped preview with no card. The only resets are stamps returning or removing and re-adding the project. This is documented as a limit in the LKM-153 PROGRESS entry.
  - Follow-up F3.
- **M4. The `setup-vite` unit test depended on Bun's global install cache.** Fixed here (see Cleanups).
  - The "bare project" case had no `node_modules`, so Bun auto-installed `@babel/core` when the plugin required it.
  - With a broken cache entry the plugin reported "could not be loaded" instead of "not installed", and quick verification failed (`worker-verify-1.log`). With a working registry, Babel would load and the expected warning would not appear at all.
  - `bun --no-install test/setup-vite.mjs` passed on the unchanged file.
- **M5. Files over the guideline.**
  - Grew in the range:
    - `src/native/Host.swift`: 618 lines, +15;
    - `src/shared/api.ts`: 1310, +26;
    - `src/main/agent.ts`: 1614, +12;
    - `src/main/backends/claude.ts`: 1576, +14;
    - `src/preview/preload.ts`: 1895, +5.
  - New: `test/helpers/island-flicker-framework-core.mjs`, 543 lines.
  - `src/native/index.ts` shrank to 551 (LKM-152 moved the startup reports to `activity-startup.ts`).
  - Splits are proposed in F5 and F6 and were not done here.

### Low

- **L1. Dead state in `NativeActivity`.** `var unread` and `var unreadLevel` in `src/native/Activity.swift` were never read or written. The real state lives in `ActivityIndicator` (`src/native/ActivityIndicator.swift`) and `NativeActivityController`. The `sheets` smoke reads `unread` from `ActivityIndicator.inspect()`, merged into `activityInspect` in `src/native/Host.swift`. Removed.
- **L2. Unused import.** `readFile` from `node:fs/promises` in `src/main/backends/claude.ts` was the only unused local that `tsc --noUnusedLocals` reported across the changed files. It predates the range. Removed.
- **L3. Unused exported type.**
  - `IslandOverrideMessage` (`src/preview/island-override.ts`) is exported and never used.
  - `islandPreviewPort` (`src/native/island-preview.ts`) sends an untyped `Record<string, string>`.
  - Typing the port with that union would make the protocol checked on the sending side. It was left as is: removing the type loses the only written description of the wire format.
- **L4. Duplicated root-prefix stripping.** `projectRelativeSource` (`src/shared/selection-context.ts`) and `projectPath` (`src/shared/dev-error.ts`) both strip `root/` from a path. F1 should give them one helper.
- **L5. Repeated unread reset.** `this.unread = 0; this.unreadLevel = 'info'; this.badge()` appears twice in `src/native/activity-controller.ts`. It is small and cosmetic.
- **L6. Coupling of setup to chat isolation.** `src/main/setup.ts` now imports `syncChatHelpers` from `src/main/chat-isolation.ts`, so the setup module depends on chat-isolation state. This is acceptable today. If `chat-isolation.ts` is split (F5), `syncChatHelpers` belongs with the helper sync, not the park logic.
- **L7. Stale line anchors.** The `src/native/Activity.swift` and `src/native/Host.swift` rows in `docs/SWIFT-BACKEND-EVENTS.md` point at old line numbers. The drift predates the range. `test/docs-links.mjs` checks paths, not line anchors.
- **L8. Lint debt added by the range.**
  - `biome check src test` went from 546 errors in 582 files (at `ee301e2`) to 576 errors in 613 files.
  - 27 of the 30 new errors are in the 28 files added by the range: 22 formatting, 5 import ordering and 1 template literal.
  - The 14 `noUnusedVariables` warnings on `SHADOW_*` constants in `test/fixtures/island-flicker-vite/src/phone.js` and `test/fixtures/next-app/app/shadow-flicker/ShadowPhone.tsx` are intentional: the island reads them from source. They need a Biome override, not a fix. Follow-up F4.
- **L9. Commit hygiene.**
  - Eight distinct LKM-140 commits share the subject "Implement LKM-140": the first pass, the fixtures, three harness iterations, the reopen fix, a docs-only evidence note and the review fix.
  - Every candidate merge is titled `Merge commit '<sha>' into HEAD`.
  - The audit below had to rely on diffs to tell them apart. Follow-up F7.
